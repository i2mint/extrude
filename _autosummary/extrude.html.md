# extrude

### Modules

| [`base`](extrude.base.html.md#module-extrude.base)           | Build composite web apps (webservice + streamlit front) from python functions.                           |
|-------------------------------------------------------------------------------------|----------------------------------------------------------------------------------------------------------|
| [`crude`](extrude.crude.html.md#module-extrude.crude)         | Control complex python object through strings.                                                           |
| [`multi_app`](extrude.multi_app.html.md#module-extrude.multi_app) | Entrypoint for dispatching multiple child applications with a navigation root.                           |
| [`testing`](extrude.testing.html.md#module-extrude.testing)     | Run a test against an app in one call: start the app, wait until it answers, run the test, stop the app. |
| [`util`](extrude.util.html.md#module-extrude.util)           | Utilities for specifying and splitting DAGs into sub-DAGs.                                               |
