extrude.multi_app

Entrypoint for dispatching multiple child applications with a navigation root.

How to prepare an application for dispatch:

extrude.multi_app.dispatch_child_apps(pathnames: Iterable[str], configs: dict = None)[source]

Recurses through a Python module to collect objects that can be dispatched to a streamlit app.

Parameters:

  • pathnames – An iterable of files and/or directory to scan through. If a filename points to a directory (a package), will look for __init__.py within that directory.

  • configs – (Optional) A dict that maps package names with configuration settings, allowing you to specify which object to import from the package and what function to use to dispatch that object to streamlit.

Example config:

{“child_pkg_1”: {“import_name”: “funcs_to_dispatch”, “dispatcher”: my_dispatcher}} config[pkgname][‘dispatch’] can be a string to refer to a dispatcher within the module, or a reference to a callable from the root app. The default dispatcher will be streamlitfront.base.dispatch_funcs.

extrude.multi_app.dispatch_child_apps_from_module(root_module: ModuleType, configs: dict = None)[source]

Takes a root Python module and scans through its immediate children to dispatch functions.

Parameters:

  • root_module – A module that contains one or more child packages to dispatch.

  • configs – (Optional) See dispatch_child_apps.

>>> import streamlit as st
>>> import extrude.examples.example_apps_simple as example_apps
>>>
>>> # this function call won't work correctly in the test environment
>>> # dispatch_child_apps_from_module(example_apps)
